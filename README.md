# 大肥鱼记忆

给 [DSH](https://github.com/deepseek-ai/dsh) 的 AI 伙伴装一份**自己的记忆**。

它做四件事：

1. **会话开头**先读几份 markdown（你是谁、你们到哪了、答应过什么），拼一条简报注入；
   被压缩之后**重新读一遍**，所以压缩不至于把"我是谁"抹掉。
2. **平时**你提到某件事，它去库里找相关段落，**只报位置不搬内容**（省 token，也少幻觉）。
3. **侧边栏多一页**：装完重启 DSH，右边栏就多一个「记忆」页，点开就是那份控制台
   （控制台会自己起来，不用你手动开）。
4. **可选**一个只读控制台：一个本地网页，看今天／记忆／健康／花费四块。
   不装 dsh-context 也不空着 —— 花费那格会换成「注入账」（插件自己记的，不用额外装东西）。

不上传、不联网、零依赖。内容全在你本机的几个 `.md` 文件里，你随时能打开改。

## 拿到手

- 仓库：<https://github.com/cazhaniyyah603-ui/dafiyu-memory>，`git clone` 下来就行
- 或者点 **Code → Download ZIP**，解压后双击里面的 `装吧.cmd`

当前版本 **1.0.4**。之前改过什么见 `改了什么-1.0.3.md`。

## 五分钟装好

**双击 `装吧.cmd`** —— 自己装完，最后停在那儿给你看结果。不用开终端、不用打命令。

> ⚠️ 别在 DSH 的对话框里跑安装器：它要写库目录和 `.dsh\profiles`，都在 DSH 工作区之外，
> 会被沙箱拒写，表现是「跑到一半卡住」。双击和普通终端都没这层。

想先看计划（什么都不动）：在这个文件夹里开一个普通 PowerShell 跑 `node 安装.mjs`。

装完跑 `node 安装.mjs --self-check`，五项全绿就对了。

插件是**复制**进 DSH 的 profile 里的，所以装完这个解压出来的文件夹可以删 —— 删了记忆照常跑，卸载也照样干净。

想搬现成的笔记／聊天记录进来：

```sh
node 导入.mjs <文件或目录>              # 只出报告
node 导入.mjs <文件或目录> --write --to <库路径>   # 真导入（只写新文件，不覆盖）
```

## 目录里有什么

| 文件 | 干什么的 |
| --- | --- |
| `安装.mjs` | 一条命令：建库、写配置、登记插件、装控制台、自检五项 |
| `导入.mjs` | 把旧笔记／聊天记录导成库文件（默认只出报告） |
| `说明书.md` | 人话版：三个槽怎么填、常见问题、边界 |
| `库模板/` | 新库的骨架（关于他、事实、状态、承诺、README） |
| `控制台/` | 只读的本地小网站（`127.0.0.1:17899`）。装完会复制进你的库 `控制台\`，里面有 `启动控制台.cmd`，双击就能看 |
| `插件/我的记忆/` | DSH 插件本体（零依赖，两个 js 文件） |
| `插件/大肥鱼面板/` | 侧边栏那一页（纯客户端：只把本机控制台套进 DSH，不重算数据；装不上不影响记忆） |

## 控制台那四块的数据哪来的

装完就有东西，不是空壳：

- **记忆**：读库里的 `.md`，按改过的时间排；点文件名直接在弹窗里看原文。
- **今天**：插件每轮把你说的话抄一行进 `生长\今天线.jsonl`。**不用装任何别的东西**。
- **健康**：只显示真的在跑的（插件日志必看；回想这类可选服务没有就不显示，不挂"未启用"）。
- **花费**：装了 dsh-context 就是它的 token 数字；没装就换成「注入账」——
  插件自己记的"今天注入了几次、平均多少字"。

## 它的边界

- **只读你的库**：除了你让它记的东西，不读别处。
- **不联网**：插件里没有任何外发请求；检索没有本地服务就退化成关键词，不报错。
- **能卸干净**：`node 安装.mjs --uninstall` 只删自己登记的插件和写的配置，**库原样留着**。
- **默认安静**：自带的"主动提一句"默认关闭；装了不会自己说话。
- 依赖 DSH 的钩子，DSH 大版本变了可能需要更新——自检第 ③ 项会最早告诉你。

## 想自己改

库就是几个 `.md` 文件，直接改就行——加一节、删一句、换个称呼，不用懂代码。

**换电脑／换位置**：拷文件夹 + `node 安装.mjs --move "<新位置>"` —— 配置和库里写死的旧路径一起改。别只跑 `--write --lib`，那只改配置不改文案。

想改**插件本身**（比如让它多读一份文件、给控制台加一块），切 DSH 的 **创造模式** 跟它说就行：
那个模式带运行时检查和插件管理工具，能直接改这个插件和它的界面。侧边栏那一页也是这么做出来的——
它本身什么数据都不算，只是一个 iframe 套着本机 `127.0.0.1:17899`（两份代码会漂，所以只套不搬）。
